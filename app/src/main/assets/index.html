Send to receiver

For Android-to-Android, use automatic discovery. For iPhone/Chromebook to Android, start the receiver and open http://RECEIVER-IP:8988 in the other device browser. Both devices must share the same Wi-Fi/hotspot.

Online transfer by code

Works in the Android app and Chromebook/desktop browser after the relay server is deployed with HTTPS. Upload a file to get a six-digit code, then enter that code on the receiving device. Files are temporary.
